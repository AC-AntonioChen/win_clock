# WinCountdown · Windows 倒计时悬浮窗

一个常驻桌面的悬浮倒计时胶囊，提醒你珍惜光阴。

- 🎯 **主目标倒计时**：显示离你设定的目标日期（如考试、纪念日）还剩多少天/时/分/秒
- ⏰ **今日关键节点轮播**：自动滚动显示距 12:30 / 17:30 / 23:00 / 今天结束 还有多久，时刻提醒时间在流逝
- 🔴 **紧迫感配色**：节点临近时主数字自动变黄→橙→红
- 🎨 **多主题**：夜墨 / 玫瑰 / 青玉 / 透明 四套预设 + 自定义十六进制颜色
- 🪟 **真透明**：每像素 alpha 透明，无难看的色块边缘
- 🖱️ **自由交互**：拖拽移动、滚轮缩放、点击切换、贴边自动隐藏

## 截图

运行后效果：深色磨砂胶囊悬浮在桌面上，显示「国庆节 剩余 67 天 12:30:45」，
每 30~45 秒轻柔地向上滑动切换到下一个倒计时项。

## 快速开始

### 方式一：直接运行（需要 Python 环境）

```bash
pip install -r requirements.txt
python floating_ball.py
```

### 方式二：打包成 exe（无需 Python 环境）

```bash
pip install -r requirements.txt
pip install pyinstaller
build.bat
```

打包后生成 `dist/WinCountdown.exe`，双击即可运行，可拷贝到任意 Windows 电脑。

## 操作说明

| 操作 | 功能 |
|------|------|
| **左键点击** | 手动切换到下一个倒计时项 |
| **左键拖拽** | 移动悬浮窗位置（位置自动记忆） |
| **鼠标滚轮** | 缩放悬浮窗大小（60%~200%，记忆） |
| **右键菜单** | 添加/删除目标、切换主题、缩放、开机自启、退出 |
| **拖到屏幕边缘** | 自动吸附并隐藏（留小标签），鼠标悬停展开 |

## 轮播规则

悬浮窗会在以下项目间循环滚动，**像新闻滚动栏一样向上轻柔滑动**：

1. **主目标**（如「国庆节 剩余 67 天」）—— 停留 **45 秒**
2. **今日节点**：距 12:30 / 17:30 / 23:00 / 今天结束 还有多久 —— 每项停留 **30 秒**
3. 循环回到主目标

- 只显示**尚未到达**的未来节点（过了 12:31 就跳过 12:30）
- 节点剩余时间不足 1 小时时，主数字从「时」切换为「分」
- 紧迫感配色：剩余 >1h 白色、30m~1h 黄、5~30m 橙、<5m 红

## 配置

配置文件 `countdown_config.json` 自动生成在同目录，结构：

```json
{
  "targets": [
    {"name": "国庆节", "date": "2026-10-01"}
  ],
  "settings": {
    "scale": 1.0,        // 缩放 0.6~2.0
    "theme": "night",    // night / rose / jade / clear / #RRGGBB
    "pos_x": 1460,       // 上次位置
    "pos_y": 237
  }
}
```

也可通过右键菜单图形化修改，无需手动编辑。

## 自定义主题

右键 → 主题 → 自定义颜色，输入十六进制（如 `#2D1B4E`）。
系统自动根据背景深浅派生协调的文字颜色（深底配亮字、浅底配深字）。

## 开机自启

右键 → 开机自启（勾选/取消）。原理是写入注册表
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，无需管理员权限。
